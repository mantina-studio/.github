# mantina.

**Vähemmän, mutta paremmin.**

Mantina on pieni, riippumaton suomalainen ohjelmistostudio, joka kehittää yksinkertaisia, laadukkaita ja maksuttomia ohjelmistoja.

Uskomme, että hyvä ohjelmisto tekee olennaisen hyvin. Ilman mainoksia, tarpeetonta monimutkaisuutta tai käyttäjän huomiosta kilpailevia ominaisuuksia.

Ohjelmistomme ovat saatavilla suomeksi ja englanniksi. Osa projekteista on avointa lähdekoodia.

---

**Less, but better.**

Mantina is a small, independent Finnish software studio creating simple, thoughtful and free-to-use software.

We believe good software should do what matters, and do it well. No ads, unnecessary complexity or features designed to compete for your attention.

Our software is available in Finnish and English. Some projects are open source.
